Diabetes Risk Prediction using KNN

Setup:
1. Download the dataset from Kaggle and place it in the same folder as the code: https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset
2. Install the required libraries by inputting the following into the terminal:

pip install pandas scikit-learn imbalanced-learn

3. Run the program

How to use:
Fill in all fields in the application and click Submit. The app will tell you whether the patient is diabetic or not.
